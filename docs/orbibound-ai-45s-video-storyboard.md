# OrbiBound AI — 45-Second Motion-Graphics Storyboard

**Purpose:** Convert the SCALEESTATE AI 96-second concept into a concise B2B explainer for OrbiBound AI.  
**Audience:** Hedge-fund analysts, supply-chain operators, and operations teams.  
**Master format:** 16:9, 1920×1080 target; compose safe center area for later 9:16 crop.  
**Duration:** 45 seconds.  
**Visual direction:** Mission-control precision, dark navy canvas, cyan satellite accent, restrained amber/red risk states, quiet premium motion graphics.  
**Production rule:** Use real OrbiBound UI/API recordings wherever the runtime capability is active. Do not fabricate satellite scenes, risk scores, alerts, or processing success.

## Core message

> From a geographic area of interest to explainable satellite-powered operational risk intelligence.

OrbiBound AI helps a user define an AOI, discover Sentinel-2 imagery, process bounded COG data, calculate an explainable anomaly risk score, and prepare threshold-based alerts. It is not presented as guaranteed prediction, investment advice, or autonomous decision-making.

## Recommended credit-saving structure

Use **five generated motion-graphics plates** and combine them with **real UI/screen captures** and editor-built titles:

1. Satellite/orbit opening plate.
2. AOI polygon lock-on plate.
3. COG data-stream processing plate.
4. Explainable risk-score plate.
5. Final operations/control-room CTA plate.

Do not generate a new character for every scene. This OrbiBound version removes the SCALEESTATE folder-carrying mascot because the satellite/map/data metaphor communicates the product faster and requires fewer consistency-sensitive generations.

## Claims and capture rules

### Safe, bounded claims

- Define and monitor a geographic AOI.
- Connect an AOI to satellite scene metadata through the configured STAC pipeline.
- Process bounded COG windows using CRS-aware measurements.
- Produce a risk score with a human-readable explanation when the required observations exist.
- Track processing status and threshold-based alert workflow when the corresponding runtime configuration is active.

### Do not claim in this video

- Guaranteed prediction or guaranteed detection.
- Guaranteed cloud-free or real-time imagery.
- Investment advice or guaranteed returns.
- Automatic trading, autonomous supply-chain decisions, or verified financial outcomes.
- A production alert delivery unless a controlled webhook/email test has passed.
- A feature as live merely because it exists in source code.
