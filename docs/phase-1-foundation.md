# Phase 1 — GitHub Foundation Structure

## Scope

This phase establishes the approved monorepo structure, shared TypeScript strictness, environment contract, documentation, placeholders, and CI skeleton.

## Deliberate exclusions

No production Supabase migration, table creation, application code, worker code, STAC requests, anomaly scoring, alert delivery, or frontend implementation is included. Those changes require their own phase approval.

## Completion criteria

- Repository structure exists on `main`.
- No credentials are committed.
- Workspace configuration is valid.
- CI configuration is present.
- Supabase target is identified and healthy; schema changes remain deferred.
- Changes are committed and pushed to `orbiboundsi/ORBIBOUNDSI` after validation.
